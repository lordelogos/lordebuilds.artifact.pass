# ArtifactPass v0.1.0-rc.9 release candidate

Date: 2026-08-28

Status: replacement staging candidate for second-PC installation testing.

## Why this candidate exists

RC8 could install successfully and later disappear from Claude's MCP list. The installer registered ArtifactPass's marketplace from the temporary package directory used by `pnpm dlx`. When that directory expired, Claude reported a marketplace `cache-miss` and stopped exposing the plugin's MCP server.

## What changed

- The complete ArtifactPass marketplace is copied into ArtifactPass's content-addressed local installation.
- Codex and Claude are registered against that durable marketplace instead of the temporary package directory.
- Direct `artifactpass connect` and the installer now use the same durable marketplace lifecycle.
- The regression suite removes the original package source and verifies that the MCP, skills, and both host marketplace manifests remain available.

## Qualification

The candidate must pass the complete release check, packed-install check, and the package-source-removal regression. An isolated Claude installation must retain `mcpServers.artifactpass` and report the plugin MCP as connected after its original package source is removed.

## Publishing

The candidate is published from the immutable `v0.1.0-rc.9` tag by `publish-candidate.yml`. GitHub OIDC trusted publishing supplies the short-lived registry credential and publishes the reviewed archive under the npm `rc` tag.
