# ArtifactPass v0.1.12-rc.3

Status: replacement release candidate for the Slack archive setup trial. The npm `latest` tag remains unchanged.

## What changed

- Slack setup no longer loads the agent-sharing publication journal or its `node:sqlite` module at startup.
- When pnpm launches ArtifactPass with Node 20, the Slack wizard still opens. Cloudflare commands use an installed Node 22+ runtime because Wrangler requires it.
- If no compatible Node is installed for Cloudflare commands, setup reports that prerequisite instead of failing with a Node stack trace.

The local SQLite journal remains part of agent publishing. It is not deployed to Cloudflare and is not used by the Slack archive Worker.

## Qualification

Run a fresh Slack archive setup from `pnpm dlx artifactpass@0.1.12-rc.3 slack setup`. The previous RC is not qualified for stable promotion.
