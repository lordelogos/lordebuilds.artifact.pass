# ArtifactPass v0.1.3

Status: stable release published directly to npm `latest`.

## What changed

- The qualified `0.1.2` registry package is promoted as a metadata-only stable successor.
- Stable tags now publish directly to npm `latest` through trusted publishing. RC tags continue to publish to npm `rc`.
- The package keeps the unified setup CLI, resumable private deployments, deployment progress UI, and version-pinned update commands qualified in `0.1.2`.

## Qualification

The release must pass the complete release gate and packed-install proof. Its registry archive must match `0.1.2` except for exact version metadata, pass an isolated install, and report a healthy existing private deployment through non-mutating checks.

Final commit, workflow, registry integrity, provenance, dist-tags, and acceptance evidence are recorded in the GitHub release.
