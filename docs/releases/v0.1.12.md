# ArtifactPass v0.1.12

Stable release of the qualified `0.1.12-rc.5` candidate.

- Adds the optional, customer-owned Slack archive setup wizard. Teams can select public ArtifactPass and up to four private link domains, choose channels, and verify real file deliveries.
- Includes the illustrated Slack archive guide on the public site.
- Keeps Slack archive setup separate from private ArtifactPass deployment.

The stable package must match RC5 after version-only normalization. Production deployment follows npm publication and the existing-resource review gate.
