# ArtifactPass v0.1.12

Stable promotion of the qualified `0.1.12-rc.1` release candidate. The package changes only version metadata from that candidate.

## What changed

- Browser navigation errors render ArtifactPass recovery pages with a next action instead of raw protocol JSON. API callers retain protocol JSON.
- Missing or expired shared links show the unavailable-artifact UI.
- Homepage sign-in popup state reconciles when authentication completes.
- The bundled MCP server dependency is updated beyond the reported high-severity advisories.

## Qualification

The release candidate passed `pnpm release:check`, packed-install and browser checks. The exact RC Worker was deployed to staging as version `96fe96e7-576c-4dad-8671-b739e8c87de0`; exact-version staging health, authentication boundaries, Google and GitHub OAuth starts, and browser recovery pages passed. The static Pages build was verified on a preview deployment. Stable publication requires packed-artifact equivalence to the npm RC after version-only normalization.
