# ArtifactPass v0.1.0-rc.6 release candidate

Date: 2026-08-28

Status: staging candidate for clean second-PC testing.

## Why this candidate exists

The external registry-install check found that `v0.1.0-rc.5` rejected the documented no-subcommand staging syntax when `--base-url` was the first argument. The installer treated the flag as a command and stopped before writing any state.

## What changed

- Valid installation flags now dispatch directly to installation without requiring an `install` subcommand.
- The documented custom-deployment command works as written.
- A regression test covers every supported no-subcommand installation flag while preserving normal help and command routing.

## Qualification

The candidate must pass the complete release check, packed-install check, and a clean install from the public npm registry. The external clean install must use the documented staging syntax, install both host adapters, return receipt v3 with no credential, and avoid browser authentication.

## Publishing

The candidate is published from the immutable `v0.1.0-rc.6` tag by `publish-candidate.yml`. GitHub OIDC trusted publishing supplies the short-lived registry credential and publishes the reviewed archive under the npm `rc` tag.
