# ArtifactPass v0.1.9

Status: stable release promoted from the qualified `0.1.9-rc.2` candidate.

## What changed

- The production homepage, privacy page, terms page, crawler rules, and sitemap are served directly from Cloudflare static assets.
- Production public pages include canonical discovery metadata without pinning the install command to a package version.
- Staging stays visibly separate, noindexed, and tied to the exact release candidate under qualification.
- Private custom-domain deployments keep their hostname-specific, non-indexed Worker rendering.
- Authentication, uploads, APIs, and artifact links remain Worker-backed.

## Qualification

`0.1.9-rc.2` passed the complete release gate, packed-install proof, registry inspection, and live staging verification. Stable publication requires byte equivalence with that candidate after version normalization.
