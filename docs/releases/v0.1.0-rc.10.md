# ArtifactPass v0.1.0-rc.10 release candidate

Date: 2026-08-29

Status: replacement candidate for Codex and organization-installation testing.

## Why this candidate exists

RC9 could fail on a Codex development machine when Codex discovered the repository marketplace but did not persist it under the ArtifactPass marketplace name. The installer treated the discovered marketplace as removable configuration and stopped when Codex reported that it was not configured.

RC9 also remembered an existing organization deployment URL and displayed it as the default answer. That made the staging URL look like a recommended value instead of an organization-specific choice.

## What changed

- Codex setup now distinguishes a discovered marketplace from a persistently configured marketplace and installs the durable ArtifactPass marketplace when needed.
- A failure after durable marketplace registration removes that new registration during rollback.
- Unexpected Codex marketplace errors still stop installation instead of being hidden.
- Organization setup always asks `Organization deployment URL:` as an open question with no remembered or example URL.

## Qualification

The candidate must pass the complete release check, packed-install check, setup regression suite, and real Codex installation proof. A rerun in an existing organization workspace must not display a deployment URL in brackets.

## Publishing

The candidate is published from the immutable `v0.1.0-rc.10` tag by `publish-candidate.yml`. GitHub OIDC trusted publishing supplies the short-lived registry credential and publishes the reviewed archive under the npm `rc` tag.
