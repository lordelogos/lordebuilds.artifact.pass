# ArtifactPass v0.1.0-rc.3 release candidate

Date: 2026-08-24

Status: development candidate for fresh-install and cross-agent release qualification.

## What changed

- Codex and Claude host registrations now bind the installed MCP bridge to the exact ArtifactPass config path and profile created by the installer.
- Both hosts launch the durable verified portable bridge rather than relying on ambient user configuration or an ephemeral package path.
- Failed multi-host installation rolls back the explicit MCP registration together with the plugin registration.

## Why this candidate exists

The external release lab proved that `v0.1.0-rc.2` could install the plugins but that a newly launched host could read an unrelated ambient ArtifactPass profile. The agent then rejected a valid temporary-workspace artifact as outside the approved roots. Under the release evidence contract, that product defect invalidated the affected `rc.2` fresh-install evidence and requires a new immutable candidate.

## Qualification boundary

Local development evidence now passes autonomous publish, read, cross-agent handoff in both directions, exact-byte reconstruction, viewer checks, and no-share safety controls. This is not release qualification: `rc.3` still requires a clean one-command install from the public registry, isolated-principal evidence, and the bounded reliability cohort.
