# ArtifactPass v0.1.7-rc.1

Status: release candidate for staging qualification. The npm `latest` tag remains unchanged.

## What changed

- Private deployment now explains that adding a domain to Cloudflare changes DNS nameservers without transferring the domain registration.
- The setup CLI links directly to an illustrated Cloudflare domain activation guide and gives the exact `example.com` input format.
- Every CLI question is documented, with normal agent installation kept separate from private Cloudflare deployment.
- The obsolete Codex/Claude-only host flags were removed from `connect`; agent selection now belongs only to workspace installation.

## Qualification

This candidate must pass the complete release gate, packed-install proof, and live staging checks. Private deployment qualification must confirm the domain handoff, all eight agent choices during normal installation, and authorization-only `connect` behavior before stable promotion.
