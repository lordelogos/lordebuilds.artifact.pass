# ArtifactPass v0.1.6

Status: stable release promoted from the qualified `v0.1.6-rc.1` candidate.

## What changed

- The website and bundled agent skills now explain every supported sharing direction: person to person, agent to person, person to agent, and agent to agent.
- Agent instructions make the recipient and handoff path explicit instead of describing sharing as a single generic flow.
- Stable releases are blocked unless the matching RC is published, deployed to staging, and verified there first.

## Qualification

The release passed the complete release gate, packed-install proof, live staging health and sign-in checks, Google and GitHub OAuth starts, and real Markdown, HTML, PDF, browser, and agent handoffs. Its package contents match `v0.1.6-rc.1` after version normalization.
