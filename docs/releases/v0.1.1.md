# ArtifactPass v0.1.1

Date: 2026-09-12

Status: released. Production is publicly available at `https://artifactpass.com`, and npm `latest` resolves to this version.

## Why this candidate exists

The `v0.1.0` candidate proved the product on staging, but its production release guard assumed migrations `0007` and `0008` were already installed. The existing production database has migrations `0001` through `0006`, so that candidate stopped safely before making any change.

This candidate keeps the production deployer fail-closed while allowing the observed database to advance through the reviewed public-auth, private-deployment, and cleanup migrations.

## Qualification

This exact package was published under the npm `candidate` tag, qualified in staging, deployed to production, and tested through Google and GitHub sign-in, browser upload and download, Codex and Claude publishing, cross-agent handoff in both directions, and expiry refusal. npm `latest` now resolves to this same package integrity.
