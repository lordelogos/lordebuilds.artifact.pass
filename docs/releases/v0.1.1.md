# ArtifactPass v0.1.1 candidate

Date: 2026-09-12

Status: contained stable candidate. Production access is not yet generally available.

## Why this candidate exists

The `v0.1.0` candidate proved the product on staging, but its production release guard assumed migrations `0007` and `0008` were already installed. The existing production database has migrations `0001` through `0006`, so that candidate stopped safely before making any change.

This candidate keeps the production deployer fail-closed while allowing the observed database to advance through the reviewed public-auth, private-deployment, and cleanup migrations.

## Qualification

This exact package is published under the npm `candidate` tag, deployed to staging, and tested before production activation. npm `latest` remains unchanged until production qualification succeeds.
