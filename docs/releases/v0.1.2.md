# ArtifactPass v0.1.2

Status: stable candidate. The package is published under npm `candidate` and moves to `latest` only after exact registry-package acceptance.

## What changed

- Private deployments show setup commands pinned to the exact ArtifactPass version that deployed them.
- The unified setup CLI, resumable private-deployment flow, and deployment progress UI from the `0.1.2` release-candidate series are included unchanged.
- Existing private deployments remain fixed to their deployed version until an administrator runs the documented update command.

## Qualification

The release commit must pass the complete release gate and packed-install proof. After publication, the registry tarball is downloaded, checked against npm integrity metadata, installed in an isolated workspace, and exercised through the public setup and non-mutating private update-review paths before `latest` moves.

Final commit, workflow, registry integrity, dist-tags, and acceptance evidence are recorded after promotion.
