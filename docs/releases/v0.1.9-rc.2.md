# ArtifactPass v0.1.9-rc.2

Status: release candidate for staging qualification. The npm `latest` tag remains unchanged.

## What changed

- Production serves the homepage, privacy page, terms page, crawler rules, and sitemap directly from Cloudflare static assets.
- Staging keeps those routes Worker-rendered so it remains noindexed, visibly marked as staging, and tied to the exact candidate being qualified.
- Private custom-domain deployments keep their hostname-specific, non-indexed Worker rendering.
- Authentication, uploads, APIs, and artifact links remain Worker-backed in every environment.

## Qualification

This candidate must pass the complete release gate, packed-install proof, registry inspection, and live staging checks before stable promotion. Stable `0.1.9` may only normalize the version metadata of this qualified candidate.
