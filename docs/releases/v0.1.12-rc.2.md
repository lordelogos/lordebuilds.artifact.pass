# ArtifactPass v0.1.12-rc.2

Status: release candidate for a clean-slate Slack archive setup trial. The npm `latest` tag remains unchanged.

## What changed

- Includes the web and authentication fixes from the previous `0.1.12` candidate.
- Adds the optional, customer-owned Slack archive Worker and local browser setup wizard to the published CLI.
- Includes the complete first-run Slack manifest, channel setup and verification steps, progress recovery, and archive status and removal commands.
- Updates the published CLI dependencies to clear the production dependency audit.

## Qualification

The complete release gate, packed-install proof, registry tarball inspection, and a fresh real-world setup from `pnpm dlx artifactpass@0.1.12-rc.2 slack setup` are required before stable promotion. Stable `0.1.12` may only normalize this qualified candidate's version metadata.
