# ArtifactPass v0.1.7

Status: stable release promoted from the qualified `v0.1.7-rc.1` candidate.

## What changed

- Private deployment now explains how to connect a domain to Cloudflare without transferring its registration.
- The domain step gives a concrete `example.com` input, links to an illustrated walkthrough, and tells the operator exactly when to return to the CLI.
- Normal agent installation lists all eight supported MCP client paths, while deployment no longer asks an unrelated agent-selection question.
- The obsolete `connect --host codex|claude|both` path has been removed from the CLI and documentation.

## Qualification

The release passed the complete release gate and packed-install proof. The exact `v0.1.7-rc.1` package was deployed to staging and passed health, protected-upload, Google and GitHub OAuth-start, Markdown, HTML, cross-agent, human-PDF, and controlled-PDF checks. Stable package contents must match that RC after version-only normalization.
