# ArtifactPass v0.1.4

Status: stable release published directly to npm `latest`.

## What changed

- Production updates now accept an existing ArtifactPass database when every reviewed migration has already been applied.
- The production approval manifest remains bound to the exact Worker bundle, OAuth inputs, Cloudflare resources, and migration state before deployment.
- Private deployment administrators receive the same updater through the unpinned `pnpm dlx artifactpass` command. Their Cloudflare deployment changes only when they explicitly run its documented update command.

## Qualification

The release must pass the complete release gate and packed-install proof. Production deployment is then approved from a freshly generated state-bound manifest, followed by health and OAuth-start verification in staging and production.

Final commit, workflow, registry integrity, provenance, dist-tags, deployment versions, and acceptance evidence are recorded in the GitHub release.
