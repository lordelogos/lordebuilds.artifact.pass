# ArtifactPass v0.1.8-rc.1

Status: release candidate for staging qualification. The npm `latest` tag remains unchanged.

## What changed

- The ArtifactPass npm page now displays the same setup-focused README as the repository.
- Release inspection fails when the npm package omits the README or its contents drift from the repository guide.

## Qualification

This candidate must pass the complete release gate, packed-install proof, registry package inspection, and live staging checks before stable promotion. Stable `0.1.8` may only normalize the version metadata of this qualified candidate.
