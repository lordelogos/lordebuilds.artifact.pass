# ArtifactPass v0.1.0-rc.11 release candidate

Date: 2026-08-29

Status: replacement candidate for installation-flow testing.

## Why this candidate exists

RC10 still presented deployment setup as a preselected menu and displayed the public URL inside an answer. The installation question must be neutral so users identify their actual deployment type before an organization URL is requested.

## What changed

Interactive setup now displays exactly:

```text
Public or organization deployment?
1. Public
2. Organization
Answer:
```

There is no URL in either answer, no parenthesized hint, and no preselected default. Answering `2` then displays `Organization deployment URL:` with no suggested value.

## Qualification

The candidate must pass the setup prompt contract test, complete setup package suite, packed-install proof, and release check.

## Publishing

The candidate is published from the immutable `v0.1.0-rc.11` tag by `publish-candidate.yml` under the npm `rc` tag.
