# ArtifactPass 0.1.2-rc.4

Private deployments now show a setup command pinned to the exact ArtifactPass version that built the deployment.

## Fixed

- Private and staging homepages no longer show the stale `0.1.1` installer command.
- Release-candidate deployments now show their exact release-candidate version.
- Production deployments continue to show the exact stable version used to build them.

The npm `latest` tag remains unchanged.
