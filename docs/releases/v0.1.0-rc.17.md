# ArtifactPass v0.1.0-rc.17 release candidate

Date: 2026-09-12

Status: replacement candidate for correct agent selection during project setup.

## Why this candidate exists

RC16 incorrectly reduced the agreed agent menu to Codex, Claude Code, and Both. That excluded the broader MCP ecosystem and could install more than one agent when the user wanted one.

## What changed

- Interactive setup now asks exactly which agent is being set up: Codex, Claude Code, Gemini CLI, Kimi Code, Cursor, VS Code / GitHub Copilot, Antigravity, or another MCP client.
- The unsupported Both choice is removed.
- `--agent` supports `codex`, `claude`, `gemini`, `kimi`, `cursor`, `vscode`, `antigravity`, or `other`.
- Non-interactive setup must pass one `--agent` value instead of silently auto-detecting and installing multiple clients.
- Gemini, Kimi, Cursor, VS Code / GitHub Copilot, and Antigravity receive project-scoped MCP configuration plus the portable ArtifactPass skills.
- Other MCP clients receive the verified portable MCP and skills paths for honest manual registration instead of a false automatic-install claim.
- Existing project MCP servers are preserved, malformed configuration fails closed, and a failed setup restores the prior files.

## Qualification

The candidate must pass the complete release gate and a packed-install proof that registers Gemini CLI in a clean project, negotiates the ArtifactPass MCP, verifies both skills, and repairs safely on rerun.
