# ArtifactPass 0.1.2-rc.3

Private deployments now show the Cloudflare stage currently running instead of leaving the completed approval prompt on screen with no visible activity.

## Fixed

- The deploy CLI starts an elapsed-time indicator as soon as deployment begins.
- The indicator follows D1, R2, access, Worker deployment, readiness, and sign-in verification.
- Successful and failed deployments now end with an explicit terminal state.

The npm `latest` tag remains unchanged.
