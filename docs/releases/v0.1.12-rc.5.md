# ArtifactPass v0.1.12-rc.5

Status: final release candidate for the optional Slack archive add-on. npm `latest` remains 0.1.11 until this candidate passes the staging gate.

## What changed since RC4

- The packaged README now explains how to start Slack archive setup and its actual Node requirements.
- The illustrated Slack setup guide uses unpinned commands and includes six product screenshots.
- The signed-in browser sharing gate now requires visible HTML preview content instead of accepting a blank frame.
