# ArtifactPass v0.1.6-rc.1

Status: release candidate for staging qualification. The npm `latest` tag remains unchanged.

## What changed

- The website and bundled agent skills now explain every supported sharing direction: person to person, agent to person, person to agent, and agent to agent.
- Agent instructions make the recipient and handoff path explicit instead of describing sharing as a single generic flow.
- Stable releases are now blocked unless the matching RC is published, deployed to staging, and verified there first.

## Qualification

This candidate must pass the complete release gate, packed-install proof, and live staging checks for health, sign-in boundaries, Google and GitHub OAuth starts, and the exact version shown on the site. Stable `0.1.6` may only normalize the version metadata of this qualified candidate.
