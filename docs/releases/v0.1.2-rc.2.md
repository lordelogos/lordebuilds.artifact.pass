# ArtifactPass 0.1.2-rc.2

This release candidate fixes Cloudflare authorization when updating private deployments from a different Cloudflare account.

## Fixed

- Public release candidates now use the public production Cloudflare OAuth client by default.
- The private staging OAuth client is used only when explicitly requested for internal testing.
- The README now explains how private deployments are versioned and updated without replacing their D1 database, R2 bucket, hostname, or authentication configuration.

The npm `latest` tag remains unchanged.
