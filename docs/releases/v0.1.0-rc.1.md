The required simplification pass removed two redundant release-script operations. The code review found and fixed the browser Access path mismatch, PDF fallback, bounded derived-text reads, connection rollback and credential-store failures, public device-flow rate limiting and cleanup, replay after a lost token response, plugin artifact drift, and release-package provenance. The remaining local advisory is that large HTML and Markdown viewers sanitize the full document on each request; this affects Worker cost, not correctness or isolation. Real dual-host invocation and all live Access/deployment checks remain release gates, not local passes.

No live gate is represented as passed until its command output is observed. The release artifact workflow builds from a frozen lockfile, reruns the release gate, emits SHA-256 checksums, and uses GitHub artifact attestations for build provenance.
