# ArtifactPass v0.1.12-rc.1

Status: release candidate for staging qualification. The npm `latest` tag remains unchanged.

## What changed

- Browser navigation errors now render ArtifactPass recovery pages with a clear next action instead of raw protocol JSON. API callers still receive protocol JSON.
- Missing or expired shared links show the unavailable-artifact UI.
- The homepage sign-in popup reconciles correctly when authentication completes.
- The bundled MCP server dependency is updated past newly reported high-severity advisories.

## Qualification

This candidate must pass the complete release gate, packed-install proof, exact-version staging deployment, browser recovery-page checks, and production Pages preview before stable promotion. Stable `0.1.12` may only normalize this candidate's version metadata.
