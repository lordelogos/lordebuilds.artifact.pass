# ArtifactPass v0.1.8

Status: stable release promoted from the qualified `v0.1.8-rc.1` candidate.

## What changed

- The npm package now includes its setup-focused README on the npm package page and in every installed tarball.
- Release inspection fails if that packaged README is absent or differs from the repository README.

## Qualification

The release passed the complete release gate and packed-install proof. The exact `v0.1.8-rc.1` package was published to npm, deployed to staging, and passed health, protected-upload, Google OAuth-start, and GitHub OAuth-start checks. Stable package contents must match that RC after version-only normalization.
