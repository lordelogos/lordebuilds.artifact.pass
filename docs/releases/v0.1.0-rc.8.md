# ArtifactPass v0.1.0-rc.8 release candidate

Date: 2026-08-28

Status: replacement staging candidate for second-PC installation testing.

## Why this candidate exists

RC7 could fail when upgrading an existing Codex or Claude installation. The host marketplace remained bound to the temporary directory used by an earlier `pnpm dlx` run, then the installer tried to load the new plugin from that expired path.

## What changed

- Existing ArtifactPass marketplaces are rebound to the current package before the host plugin is upgraded.
- Codex and Claude upgrade through the same current marketplace bytes.
- A failed installation now prints the underlying redacted host error.
- Failure output no longer claims that previous state was restored when that cannot be proven.

## Qualification

The candidate must pass the complete release check, packed-install check, and the stale-marketplace regression. An isolated Claude installation previously bound to a removed marketplace must then upgrade successfully without opening a browser.

## Publishing

The candidate is published from the immutable `v0.1.0-rc.8` tag by `publish-candidate.yml`. GitHub OIDC trusted publishing supplies the short-lived registry credential and publishes the reviewed archive under the npm `rc` tag.
