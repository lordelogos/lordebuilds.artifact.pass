# ArtifactPass v0.1.5

Status: stable hotfix published directly to npm `latest`.

## What changed

- Production updates now verify both valid upload boundaries: Cloudflare Access containment before public activation, and ArtifactPass sign-in after the approved public bypass policy is active.
- The updater no longer reports a failed deployment after successfully updating an already activated production Worker.
- Existing private deployments remain unchanged until their administrator explicitly runs the documented update command.

## Qualification

The release must pass the complete release gate and packed-install proof. The deployment verifier is exercised against both production boundary states, followed by health and OAuth-start verification in staging and production.

Final commit, workflow, registry integrity, provenance, dist-tags, and deployment versions are recorded in the GitHub release.
