# ArtifactPass v0.1.10-rc.1

Status: release candidate for staging qualification. The npm `latest` tag remains unchanged.

## What changed

- The public site now has dedicated static pages for how ArtifactPass works, AI-agent workflows, private Cloudflare deployments, and security.
- Search metadata, internal links, crawler rules, and the sitemap now describe the product with focused, indexable routes.
- The npm package now points to `artifactpass.com` and declares keywords for artifact sharing, AI agents, MCP, temporary file sharing, Markdown, HTML, PDF, and Cloudflare.
- Shared artifact routes and private deployment surfaces remain non-indexed.

## Qualification

This candidate must pass the complete release gate, packed-install proof, registry inspection, and live staging checks before stable promotion. Stable `0.1.10` may only normalize the version metadata of this qualified candidate.
