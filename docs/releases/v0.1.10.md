# ArtifactPass v0.1.10

Status: stable release promoted from the qualified `0.1.10-rc.2` candidate.

## What changed

- The public site now has focused, static pages for how ArtifactPass works, AI-agent workflows, private Cloudflare deployments, and security.
- Search metadata, internal links, crawler rules, and the sitemap now describe the product through indexable public routes.
- The npm package points to `artifactpass.com` and carries focused discovery keywords for artifact sharing, AI agents, MCP, temporary file sharing, supported formats, and Cloudflare.
- Shared artifact links and private deployment surfaces remain non-indexed.
- Release qualification now proves the exact package version running on staging before stable promotion.

## Qualification

`0.1.10-rc.2` passed the complete release gate, packed-install proof, registry inspection, and exact-version live staging verification. Stable publication requires byte equivalence with that candidate after version normalization.
