# ArtifactPass v0.1.0-rc.16 release candidate

Date: 2026-09-11

Status: candidate for explicit agent selection during workspace setup.

## Why this candidate exists

The previous installer inferred which supported agents to configure. That made the one-command setup depend on local machine state and could configure more than the user intended.

## What changed

- Interactive setup asks whether to install ArtifactPass for Codex, Claude Code, or both before asking about the deployment.
- `--agent codex`, `--agent claude`, and `--agent both` provide the same choice for scripted setup.
- Only the selected host is installed.
- Non-interactive API callers without `--agent` keep the existing host auto-detection behavior for compatibility.
- A failed host installation now records the selected hosts and any incomplete rollback truthfully.

## Qualification

The candidate must pass the complete release gate, packed-install proof, and a real terminal rehearsal showing the agent prompt and the `--agent` bypass.
