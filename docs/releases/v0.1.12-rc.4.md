# ArtifactPass v0.1.12-rc.4

Status: release candidate for the Slack archive setup wizard. The npm `latest` tag remains unchanged.

## What changed

- The wizard uses consistent controls, typography, and button states across its steps.
- On narrow screens, setup content scrolls as one page without a nested card or horizontal overflow.
- The complete Slack archive flow remains separate from private ArtifactPass deployment.

## Qualification

Install the candidate with `pnpm dlx artifactpass@0.1.12-rc.4 slack setup`. Complete a fresh setup and verify that a new ArtifactPass link posted in each selected Slack channel produces the expected file in its thread. This RC is not qualified for stable promotion until that live flow passes.
