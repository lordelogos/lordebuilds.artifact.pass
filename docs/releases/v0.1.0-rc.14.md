# ArtifactPass v0.1.0-rc.14 release candidate

Date: 2026-09-03

Status: replacement candidate for workspace-bound MCP authentication tests.

## Why this candidate exists

RC13 passed its complete release gate, but npm rejected its explicit provenance bundle because the GitHub source repository was private. npm trusted publishing supports private repositories, but npm provenance currently requires a public source repository.

## What changed

RC14 contains the same workspace-bound MCP authentication fix as RC13. Its publishing workflow now:

- uses tokenless npm trusted publishing for both public and private source repositories;
- requests npm provenance when the source repository is public;
- omits the unsupported provenance request while the source repository remains private.

## Qualification

The candidate must pass the workspace-routing regression tests, portable MCP contract, package and plugin checks, packed-install proof, and the complete release gate.

## Publishing

The candidate is published from the immutable `v0.1.0-rc.14` tag by `publish-candidate.yml` under the npm `rc` tag.
