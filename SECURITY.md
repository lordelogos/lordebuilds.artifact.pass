# Security policy

## Supported versions

Security fixes are provided for the latest published release candidate or stable release. Deployments remain customer-operated, so administrators must apply updates to receive fixes.

## Report a vulnerability

Use GitHub private vulnerability reporting for this repository. Do not open a public issue, include a live share URL in a report, or send Cloudflare, Access, agent, or share credentials. Include affected version, impact, reproduction steps using synthetic data, and any proposed mitigation.

If private vulnerability reporting is unavailable, open a public issue containing no exploit or secret and ask the maintainers for a private contact channel.

We will acknowledge a private report, validate it, coordinate a fix and disclosure window, and credit the reporter when requested. There is currently no paid bug-bounty program.
